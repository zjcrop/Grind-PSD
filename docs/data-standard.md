# Grind-PSD 数据标准

## 1. 标准目的

Grind-PSD 的目标不是替代激光粒度仪或显微图像法，而是建立一个咖啡爱好者、烘焙商和器具开发者都能复现的筛分口径。所有公开记录必须使用同一套字段和同一套筛层定义，才能进行横向比较。

当前标准 ID：

```text
grind-psd-sieve-v1
```

## 2. 筛层与字段

| 字段 | 筛层 | 标称区间 | 单位 |
|---|---:|---:|---:|
| `mesh18_retained_g` | 18 目筛上 | `>=1000 μm` | g |
| `mesh24_retained_g` | 24 目筛上 | `800-1000 μm` | g |
| `mesh35_retained_g` | 35 目筛上 | `500-800 μm` | g |
| `mesh60_retained_g` | 60 目筛上 | `300-500 μm` | g |
| `pan80_lt300_g` | 80 目底盘极细粉 | `<300 μm` | g |

这里的孔径区间沿用项目原始工具的标称体系，重点是保证社区内部的相对可比性。不同国家标准筛、不同厂家筛具和咖啡粉形貌都会造成真实开孔与有效通过概率差异，提交者应尽量记录筛具来源、摇筛时长和方法。

## 3. 推荐测量流程

1. 清洁筛具和接粉容器，确认没有上一次测量残留。
2. 称量投粉量，建议 10 g 或 15 g，记录到 `sample.doseG`。
3. 研磨后尽快筛分，避免长时间吸湿或静电状态变化。
4. 按 18 / 24 / 35 / 60 目和底盘顺序叠放筛具。
5. 使用固定方式摇筛，例如“手动摇筛 60 秒”，并在 `sample.method` 中记录。
6. 分别称量各筛层筛上粉重，单位保留到 0.01 g。
7. 若筛分总重与投粉量偏差超过 8%，建议复测或在备注中说明原因。

## 5. 指标解释

- 粗粉占比：`mesh18_retained_g / totalG`。
- 极细粉占比：`pan80_lt300_g / totalG`。
- D10 / D50 / D90：基于五段筛分累计通过率的线性插值，只能作为近似比较指标。
- 跨度：`(D90 - D10) / D50`，用于描述分布宽窄。

由于咖啡颗粒形貌不规则，筛分法的 D 值与激光粒度仪的体积分布 D 值不可直接互换。

## 6. 社区数据库规则

- `user.id` 只允许小写字母、数字、下划线和连字符。
- 同一条记录的 `id` 用于去重；重复提交会被工作流跳过。
- 总库位于 `data/database.json`，用户独立文件位于 `data/users/<user_id>.json`。
- 不接受缺失必填字段、总重为零、负数重量或非本标准 ID 的记录。
- 公开数据库不保存图片、人脸、地理位置、联系方式或其他不必要个人信息。
