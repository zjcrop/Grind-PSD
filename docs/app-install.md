# Grind-PSD App 安装说明

Grind-PSD 采用 PWA（渐进式 Web App）。同一套代码同时服务网页与安装版，不会把 GitHub Client Secret、私钥或仓库写令牌放入手机 App。

## Android

1. 用 Chrome 或 Edge 打开 <https://zjcrop.github.io/Grind-PSD/>。
2. 点击页面顶部“安装 App”；若浏览器未弹出安装框，打开浏览器菜单。
3. 选择“安装应用”或“添加到主屏幕”。

## iPhone / iPad

1. 用 Safari 打开网站，不要使用微信内置浏览器。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”。

## Windows / macOS

使用 Chrome 或 Edge 打开网站，点击地址栏安装图标，或使用页面顶部“安装 App”。

## 离线与数据

- 首次联网加载后，记录、历史、3D 图和对比功能可以离线使用。
- 首次使用会显示登录/注册窗口；保存登录状态后，再次打开直接进入主界面。
- 本地记录保存在浏览器/已安装 App 的站点存储中；卸载 App、清理浏览器网站数据或更换设备前应先导出 JSON。
- v5.1 暂停社区上传、自动同步、线上编辑和删除，账户与记录全部保存在本地。
- PWA 与网页共享同一数据模型，但不同浏览器或不同设备不会自动同步本地记录。
